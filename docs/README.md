# Evidencias de SmartCampus

Guarda las capturas originales en esta carpeta con extensión `.jpeg`. Usa el nombre indicado para cada imagen y evita incluir credenciales, datos personales o pantallas de configuración de Firebase.

| Archivo JPEG | Evidencia sugerida |
| --- | --- |
| `01-inicio.jpeg` | Bienvenida y accesos a los módulos. |
| `02-actividades-lista.jpeg` | Lista de actividades con una tarjeta desplegada y sus acciones. |
| `03-actividades-formulario.jpeg` | Formulario flotante de creación o edición con datos de prueba. |
| `04-actividades-eliminar.jpeg` | Confirmación flotante antes de eliminar una actividad. |
| `05-usuarios.jpeg` | Tarjetas de usuarios y búsqueda por nombre. |
| `06-dispositivo-sensor.jpeg` | Sensor activo con los tres ejes registrados en un teléfono. |
| `07-dispositivo-lectura.jpeg` | Lectura recuperada después de volver a abrir la aplicación. |

Cuando agregues las fotos, copia este bloque al README principal para mostrar la galería. Incluye las líneas de las imágenes que ya estén en la carpeta.

```markdown
![Inicio de SmartCampus](docs/01-inicio.jpeg)
![Lista de actividades y sus acciones](docs/02-actividades-lista.jpeg)
![Formulario flotante de actividades](docs/03-actividades-formulario.jpeg)
![Confirmación para eliminar una actividad](docs/04-actividades-eliminar.jpeg)
![Directorio y búsqueda de usuarios](docs/05-usuarios.jpeg)
![Lectura en tiempo real del acelerómetro](docs/06-dispositivo-sensor.jpeg)
![Lectura recuperada del almacenamiento local](docs/07-dispositivo-lectura.jpeg)
```
